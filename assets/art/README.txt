Card art goes in this folder as <card-key>.webp  (for example kapre.webp, tikbalang.webp, lakas.webp).

Nilalang (creature) art:  about 700 x 626 px  (the window in assets/frame-n.webp is ~888 x 794)
Orasyon / Anting-anting art: about 700 x 570 px  (the window in assets/frame-o.webp is ~905 x 735)

Art is placed BEHIND the frame, so it only needs to cover the window. If a creature has no art file the card shows an
"ART" placeholder. If an Orasyon has no art file it shows the misty default background (assets/bg-o.webp).

Optional board backgrounds (not included yet): put assets/bg-day.webp and assets/bg-night.webp (about 1920 x 1080).
